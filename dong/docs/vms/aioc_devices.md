# Quản lý Camera trên AIOC

Địa chỉ truy cập: https://aioc.atin.vn/devices

## Đăng nhập
Sử dụng tài khoản được cấp bởi quản trị viên hệ thống để đăng nhập vào portal AIOC.

## Quản lý Camera
1. Chọn menu "Quản lý thiết bị" hoặc "Devices".
2. Chọn "Camera".
3. Nhấn "Thêm mới" để thêm camera. Điền các thông tin: tên camera, địa chỉ IP, cổng, tài khoản RTSP.
4. Nhấn "Lưu" để hoàn tất.

Để vẽ sơ đồ thêm camera, có thể dùng:
Đăng nhập -> Menu Devices -> Camera -> Thêm mới -> Điền IP/RTSP -> Lưu.
